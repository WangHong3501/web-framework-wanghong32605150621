核心概念：后端路由 vs 前端路由
后端路由（早期网站）
URL ↔ 服务器真实资源一一对应；地址一变就发请求，返回整个新页面 → 整页刷新、服务器压力大
前端路由（本课主角）
URL ↔ 页面里的组件一一对应；地址变了由前端 JS 换组件，不发请求、不整页刷新 → SPA（整个站只有一个 HTML）
💡 第 4 章 <component :is> 已能换组件，但地址栏不动（不能收藏/分享/后退）。路由 = 升级成官方版 <router-view>，还多了传参、守卫、历史记录。

① 点三个链接：#/user/1、#/user/2、#/user/9527，用户ID 跟着变——一条规则服务一族
② 从列表进入 User，Console 每次打印"User 组件挂载了：几"
③ 惊天秘密：地址栏直接把 #/user/1 改成 #/user/2（不经过列表），数字变、观看次数变，但 Console 没有新"挂载了"、只有"参数变了：2"——同组件复用不重建
真实项目：进入用户页要发请求 → mounted 发一次 + watch 里参数变了再发，两处都要写。
✅ 检查点 3：三种传参都点过；能口述 $route.params.id；"直达不重挂、要 watch"现象能解释
🐣 初学者卡点 3
现象原因 / 解决
用户ID 后面是空path 没带 :id，或取参写成 .ID（大小写）→ 规则与取参逐字符对齐
写法② 跳 /user/ 报 404:to 少冒号或 id 拼错 → :to="'/user/' + id"，引号数清楚
直达 /user/2 数据不更新同组件复用、mounted 不跑 → watch '$route.params.id' 自己刷新
$route 写成 $router问路 route / 开车 router → 跳转用 router、信息用 route
同前缀规则撞车/user/:id 不会抢 /users（路径段完整匹配），但养成"具体在前、宽泛在后"

实验 07 · 路由守卫 beforeEach 登录拦截（5.6）
涉及文件
Login.vue（views/07-guard/）
🔐 登录页 ｜ 登录状态 data isLogin（查 token）
未登录按钮：login(){ localStorage.setItem('token','abc123'); this.isLogin=true; this.$router.push('/center') }

router/index.js（增量 + 守卫）
import Login ｜ { path:'/login', component:Login }
router.beforeEach((to, from, next) => {
　 if (to.path==='/center' || to.path.startsWith('/center/')) {
　　 if (localStorage.getItem('token')) { next() } else { next('/login') }
　 } else { next() } })
三参数 & 守卫家族
to 去哪（to.path）｜from 从哪来｜next 放行：next() 放行 / next('/login') 改道，每个分支都必须调，忘了整站卡死
📖 守卫家族：beforeEach（全局前置，本课主角）｜afterEach（全局后置，无 next）｜beforeEnter（路由独享）｜beforeRouteEnter/Update/Leave（组件内）
实验操作（拦截—放行—再拦截）
① 访问 #/login 点"退出"（保证无 token）
② 点"用户中心"想去 /center，却落到 #/login，写着"未登录"（被拦）
③ 点"登录"，token 写入、自动跳进 /center，"用户中心"亮（放行）
④ 退出后访问 #/center/orders，子路由一样被拦（startsWith 前缀全覆盖）
✅ 检查点 7：三部曲都走过；能口述 to/from/next；"忘调 next 卡死"能说出后果
🐣 初学者卡点 7
现象原因 / 解决
点什么都没反应、卡住某分支忘调 next() → 每个分支以 next() 或 next('地址') 收尾
所有页面都被拦到 /login判断写反/太宽 → 只命中会员区才拦，其余 next()
登录后还是被拦token 没写或 key 不一致 → 统一 setItem/getItem('token')
直接访问 /center/profile 没被拦只判断了 ==='/center' → 加 startsWith('/center/') 覆盖子路由
改守卫代码不生效热更新失灵 → 整页刷新（F5）再试

术语速查表（17 个新词）
后端路由：URL 对应服务器资源，切换即请求整页
前端路由：URL 对应组件，JS 切换、不刷新
SPA：单页应用，只有一个 HTML，翻页全是换组件
vue-router：Vue 官方路由插件，@4 配 Vue3
createRouter：创建路由器实例的工厂函数
createWebHashHistory：hash 模式，地址带 #
routes 路由表：path↔component 规则数组，从上往下匹配
router-link：声明式导航，渲染成 a 不刷新，自带高亮
router-view：路由出口，匹配到谁渲染谁
redirect：访问 A 自动跳 B 的配置项
:pathMatch(.*)*：通配符，兜住一切未配置地址（404）
动态路由 / :id：path 占位参数，一条规则匹配一族
$route.params：当前地址的路径参数对象
children：嵌套子规则数组，子 path 不带斜杠
命名路由 / params：规则 name 标识 + 按名跳转参数
$router.push / replace：编程式跳转，压历史 / 顶历史
beforeEach：每次跳转前的全局检查（to/from/next）

第 05 课 · CH05-ROUTING
前端路由 vue-router —— 单页应用的"多页面"
一句话：URL 变 → 组件换 → 页面不刷新，这就是 SPA（单页应用）的骨架
vue-router 4.6.4 选项式 this.$router / $route hash 模式（地址带 #） 7 个小实验逐个点亮
① 为什么需要路由
后端路由（早期网站）
URL ↔ 服务器上的真实资源 一一对应；地址一变就发请求，服务器返回整个新页面 → 每次整页刷新、服务器压力大
前端路由（本课主角）
URL ↔ 页面里的组件 一一对应；地址变了由前端 JS 换组件，不发请求、不整页刷新 → 整个站只有一个 HTML
💡 承接第 4 章：手搓的 <component :is> 已能换组件，但地址栏不动（不能收藏/分享/后退）。路由 = 把它升级成"官方版" <router-view>，还多了传参、守卫、历史记录一整套。

③ 七大核心能力（对应实验 01—07）
实验 01 · 基础路由
router-link：导航，渲染成 <a>，拦截点击不刷新，自动加 router-link-active 高亮
router-view：出口，地址匹配到谁，谁显示在这里
验证：切换时 Network 零请求 = 前端路由铁证
实验 02 · 重定向与 404
重定向：{ path:'/', redirect:'/home' } 放最前（值是地址字符串，不是组件）
404 兜底：/:pathMatch(.*)* 通配符殿后
规则从上往下、先到先得；通配符放前面会劫走所有地址
实验 03 · 动态路由
占位符 /user/:id 一条规则匹配一族（/user/1、/user/9527）
取参：$route.params.id；传参 3 写法：字符串 / :to 拼接 / 对象 path
⚠️ 复用坑：/user/1 直达 /user/2 不重挂组件，mounted 只跑一次 → 要 watch '$route.params.id'
实验 04 · 嵌套路由
用 children:[...] 再配子规则，外壳里放第二级 router-view
子规则 path 不带开头斜杠：'profile' 自动拼成 /center/profile
空路径重定向：{ path:'', redirect:'/center/profile' }
类比：顶层出口是商场大门，子出口是商场里的店铺（换店铺不换商场）
实验 05 · 命名路由
规则加 name:'user'，跳转按名字找：
:to="{ name:'user', params:{ id:9527 } }"
✅ 路径与跳转解耦：把 /user/:id 改成 /member/:id，命名写法一个不用改
实验 06 · 编程式导航
$router.push(...) 代码跳转（4 写法）；$router.replace(...) 顶掉历史
push 压栈（能后退）｜replace 后退回不来（登录后防回退表单）
query：?kw=vue，用 $route.query.kw 取
坑：path 与 params 同用，params 被忽略
实验 07 · 路由守卫（全局前置）
每次跳转之前执行：router.beforeEach((to, from, next) => {...})
to 去哪 ｜ from 从哪来 ｜ next 放行函数
next() 放行 ｜ next('/login') 改道登录页
⚠️ 每个分支都必须调 next()，忘了调导航直接卡死、点什么都没反应
场景：/center 是会员区，查 localStorage 有没有 token：有→放行，无→拦去 /login；判断用 startsWith 覆盖子路由

🧠 记忆口诀
· 问路 route，开车 router
· redirect 放最前，通配符殿后

· 复用不重挂，参数变化找 watch
· 嵌套 children，子 path 不带斜杠
